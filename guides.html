    Lands - Город/Создание/Основные Команды.

    Ниже приведён список команд для управления приватами в поселении. Каждая команда имеет своё назначение и особенности использования.

    Скриншот сделан игроком

    Общение и справка:

    • /lands chat (город) - Позволяет общаться внутри города.
    • /lands help - Вызывает справку по командам.
    • /lands info - Просмотр статистики привата.
    • /lands invites - Просмотр текущих приглашений.
    • /lands player - Просмотр информации об игроке, касаемо привата.

    Управление приватами:

    • /lands list, /lands land, /lands lands - Показывает список ваших приватов.
    • /lands selection - Выдаёт инструмент для выделения привата.
    • /lands leave (город) confirm - Позволяет покинуть приват. Примечание: Если вы являетесь владельцем привата, система предложит его удалить.
    • /lands delete (город) confirm - Удаляет выбранный приват.
    • /lands rename - Переименовывает приват. Требуется 5000 фрилов.
    • /lands setrole (игрок) (ранг) - Назначает роль игроку.
    • /lands setspawn - Устанавливает точку спавна привата. Требуется 500 фрилов.
    • /lands spawn (город) - Телепортирует вас к точке спавна привата. Стоимость 500 фрилов.

    Доверие и управление доступом:

    • /lands trust (игрок) (регион) - Добавляет игрока в город или конкретный регион.
    • /lands untrust (игрок) - Отменяет приглашение игрока.

    Управление чанками привата:

    • /lands unclaimall - Снимает все чанки с привата.
    • /lands unclaim - Снимает все чанки с привата.
    • /lands unclaim auto - Позволяет автоматически снять чанки, пройдя по нужным участкам. Для отключения выполните команду повторно.

    Финансовые операции:

    • /lands balance - Проверяет состояние баланса города.
    • /lands deposit (город) (сумма) - Вносит указанное количество фрил в город.
    • /lands withdraw (город) (сумма) - Выводит указанное количество фрил из города.

    Отклонение приглашений:

    • /lands deny - Отклоняет приглашение в поселении.

    Эти команды помогут вам эффективно управлять приватами, правами доступа и финансами в вашем поселении. Используйте их для создания комфортной и безопасной среды для всех участников!

    Lands - Уровни города/Повышение уровня.

    LVL 1: "Деревушка"

    Выдается сразу после создания города. (Стоимость создания 1000 фрилов)

    • +15 чанков.
    • +0% стоимости содержания.


    LVL 2: "Деревня"

    Условия для повышения:

    • Пригласить в город 4 персон.
    • Казна города должна содержать не менее 5000 фрилов.

    Атрибуты при повышении:

    • +20 чанков.
    • +5% к стоимости содержания.


    LVL 3: "Город"

    Условия для повышения:

    • Пригласить в город 12 персон.
    • Казна города должна содержать не менее 12000 фрилов.

    Атрибуты при повышении:

    • +30 чанков.
    • +10% к стоимости содержания.


    LVL 4: "Провинциальный городок"

    Условия для повышения:

    • Пригласить в город 25 персон.
    • Казна города должна содержать не менее 20000 фрилов.

    Атрибуты при повышении:

    • +50 чанков.
    • +15% к стоимости содержания.


    LVL 5: "Мегаполис"

    Условия для повышения:

    • Пригласить в город 40 персон.
    • Казна города должна содержать не менее 50000 фрилов.

    Атрибуты при повышении:

    • +80 чанков.
    • +20% к стоимости содержания.
