    Lands - Создание/Управление/Основные Команды.

    Ниже приведён список команд для управления городом. Каждая команда имеет своё назначение и особенности использования.

    Общение и справка:

    • /lands chat - Позволяет общаться внутри города.
    • /lands help - Вызывает справку по командам.
    • /lands info - Просмотр статистики привата.
    • /lands invites - Просмотр текущих приглашений.
    • /lands player (игрок) - Просмотр информации об игроке, касаемо города.

    Управление городом:

    • /lands list - Показывает весь список городов.
    • /lands selection - Выдаёт инструмент для выделения границ города.
    • /lands leave (город) confirm - Позволяет покинуть город. Примечание: Если вы являетесь владельцем города, система предложит его удалить.
    • /lands delete (город) confirm - Удаляет выбранный город.
    • /lands rename - Переименовывает город. Требуется 5000 фрилов.
    • /lands setrole (игрок) (город) (роль) - Назначает роль игроку.
    • /lands setspawn - Устанавливает точку спавна города. Требуется 500 фрилов.
    • /lands spawn (город) - Телепортирует вас к точке спавна города. Стоимость 500 фрилов.

    Доверие и управление доступом:

    • /lands trust (игрок) (регион) - Добавляет игрока в город или конкретный регион.
    • /lands untrust (игрок) - Отменяет приглашение игрока.

    Управление чанками города:

    • /lands create (название города) - Создание города на первом чанке где вы стоите. Стоимость 1000 фрилов.
    • /lands claim - Приватит чанк для города. Стоимость 100 фрилов + повышение налога.
    • /lands unclaim - Освободить чанк города. Возвращение 50 фрилов + снижение налога.
    • /lands unclaim auto - Позволяет автоматически снять чанки, пройдя по нужным участкам. Для отключения выполните команду повторно.

    Финансовые операции:

    • /lands balance - Проверяет состояние фрил города.
    • /lands deposit (сумма) - Вносит указанное количество фрил в город.
    • /lands withdraw (сумма) - Выводит указанное количество фрил из города.

    Отклонение приглашений:

    • /lands deny - Отклоняет приглашение в поселении.

    Эти команды помогут вам эффективно управлять приватами, правами доступа и финансами в вашем поселении. Используйте их для создания комфортной и безопасной среды для всех участников!

    Lands - Уровни города/Повышение уровня.

    LVL 1: "Деревушка"

    Выдается сразу после создания города. (Стоимость создания 1000 фрилов)

    • +15 чанков.
    • +0% стоимости содержания.


    LVL 2: "Деревня"

    Условия для повышения:

    • Пригласить в город 4 игроков.
    • Казна города должна содержать не менее 5000 фрилов.

    Атрибуты при повышении:

    • +20 чанков.
    • +5% к стоимости содержания.


    LVL 3: "Город"

    Условия для повышения:

    • Пригласить в город 12 игроков.
    • Казна города должна содержать не менее 12000 фрилов.

    Атрибуты при повышении:

    • +30 чанков.
    • +10% к стоимости содержания.


    LVL 4: "Провинциальный городок"

    Условия для повышения:

    • Пригласить в город 25 человек.
    • Казна города должна содержать не менее 20000 фрилов.

    Атрибуты при повышении:

    • +50 чанков.
    • +15% к стоимости содержания.


    LVL 5: "Мегаполис"

    Условия для повышения:

    • Пригласить в город 40 человек.
    • Казна города должна содержать не менее 50000 фрилов.

    Атрибуты при повышении:

    • +80 чанков.
    • +20% к стоимости содержания.


    Lands - Выдача и настройка ролей в городе.

    Каждая роль в городе (если вы являетесь владелецом или уполномочены им) настраивается индивидуально. Владелец может дать определённой роли в области право редактировать другие роли.

    Пошаговая инструкция:

    • Выполните команду /lands - Перенесёт вас в главное меню вашего города.
    • Перейдите в раздел Роли.
    • Нажмите кнопку Создать роль. (Роль «Участник» создаётся по умолчанию, поэтому создавайте дополнительные роли только если хотите наделить кого-то особыми правами.)
    • После создания роли вы можете задать ей приоритет. Это необходимо для того, чтобы данная роль могла редактировать роли, расположенные ниже по иерархии, если вы выдали ей соответствующее право.
    • Откройте созданную роль для детальной настройки.
    • Здесь вы увидите два типа флагов: Флаги управления и Флаги действия
    • Флаги управления - отвечают за права управления (например, возможность редактировать роли ниже).
    • Флаги действия - определяют дополнительные возможности для игроков, связанные с выполнением действий (открытие сундуков, дверей, строительство, разрушение блоков и т.д.).

    Настройка приватных областей:

    • Приватные области создаются для настройки ролей непосредственно на участке.
    • Приватность настраивается через выдачу ролей с определёнными правами: Открытие сундуков и дверей и Возможность ставить или ломать блоки и т.д.
    • Роль «Недоверенный» - Эта роль назначается любому игроку, независимо от города. Для неё можно установить флаг действия, позволяющий, например, открывать сундуки в выбранной области.
    • Область «По умолчанию» - Это первая область, которая охватывает весь город, если на его территории нет других областей. Для обеспечения безопасности можно для роли Участник отключить права на строительство, разрушение блоков и открытие сундуков, а затем настраивать права уже для новых областей, добавляя или создавая специальные роли.

    Выдача ролей:

    • /lands setrole (игрок) (название области) (название роли) - Выдает созданную роль игроку

    Теперь вы знаете, как настраивать и выдавать роли в вашей Земле. Настраивайте права по своему усмотрению и управляйте территориями с максимальным удобством!


    Lands - Создание приватной области внутри города.

    Шаг 1. Запуск инструмента выделения

    • /lands selection - Инструмент активируется, и вы можете выбрать две точки. Это может быть внутри одного или нескольких чанков – можно даже выделить углы всего чанка.

    Шаг 2. Расширение выделенной области по высоте

    • /lands selection expand (блоков вниз) (блоков вверх)
    • Назначение: - Расширяет выделенную область по вертикали (вниз и вверх) до самых нижних и верхних точек.
    • Примечание: - Если вы создаёте приват в небольшой комнате (например, в доме или общежитии), этот шаг можно пропустить.

    Шаг 3. Создание области

    • /lands assign (название области) - Это создаст область с выбранным вами названием.
    • Перейдите в меню /lands. В левом верхнем углу, в разделе Области, будет отображён список всех областей вашего города.
    • В области По умолчанию можно перейти в раздел Роли, где можно настроить флаги действий для роли Участник (например, запретить Break и Place блоков).
    • В созданной вами области также можно задать флаги, чтобы участник мог, например, открывать сундуки (включите флаг открытия контейнеров).

    Шаг 4. Приглашение участников в область

    • Перейдите в раздел Участники внутри нужной области.
    • Нажмите на зелёную иконку Добавить.
    • Важно: Добавлять можно только участника вашего города.
    • Для принятия приглашения игрок должен выполнить команду: /lands accept (название участка)

    Дополнительно:

    • Если команда /lands accept не сработает, попробуйте /lands invites

    Lands - Уровни города/Повышение уровня.

    LVL 1: "Федерация"

    Условие для создания:

    • Стоимость создания 40к фрилов.
    • Уровень города должен быть 3 уровень и выше.

    Атрибуты при повышении:

    • +50 чанков.
    • +0% стоимости содержания.


    LVL 2: "Нация"

    Условия для повышения:

    • Пригласить в нацию 3 города.
    • Во всех городах нации должно быть не менее 32 игроков.
    • Баланс нации должен составлять не менее 100к фрилов.

    Атрибуты при повышении:

    • +100 чанков.
    • +10% к стоимости содержания.
    • +1 активный эффект на территории нации.


    LVL 3: "Империя"

    Условия для повышения:

    • Пригласить в нацию 6 городов.
    • Во всех городах нации должно быть не менее 64 игроков.
    • Баланс нации должен составлять не менее 250к фрилов.

    Атрибуты при повышении:

    • +200 чанков.
    • +20% к стоимости содержания.
    • +3 активных эффекта на территории нации.
